# Déploiement Netlify

Ce projet est prêt pour un déploiement statique sur Netlify.

## Méthode la plus simple

1. Ouvrir votre compte Netlify.
2. Cliquer sur "Add new site" puis "Deploy manually".
3. Glisser-déposer tout le dossier `Sall Immobilier Projet` dans la zone d'import.
4. Attendre la publication du site.
5. Copier le lien Netlify généré et l'envoyer à l'entreprise.

## Méthode via dépôt Git

1. Mettre ce projet sur GitHub.
2. Dans Netlify, cliquer sur "Add new site" puis "Import an existing project".
3. Choisir GitHub et sélectionner le dépôt.
4. Vérifier que le dossier publié est la racine du projet.
5. Lancer le déploiement.

## Réglages importants

- Le fichier `netlify.toml` est déjà configuré.
- Le site est statique, il n'a pas besoin de commande de build.
- La page d'accueil est `index.html`.

## Avant d'envoyer le lien au client

- Vérifier les textes finaux
- Vérifier les vrais biens et les photos
- Vérifier l'adresse exacte et les horaires
- Vérifier les liens WhatsApp et téléphone

## Conseils

- Pour un lien plus professionnel, ajouter ensuite un nom de domaine personnalisé.
- Pour récolter des suggestions client, le lien Netlify temporaire suffit largement.
